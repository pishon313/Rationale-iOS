# Rationale iOS

Native iPhone companion for Rationale, built with SwiftUI and SwiftData.

## Requirements

- Xcode 26 or later
- iOS 17 or later

## Run

Open `Rationale.xcodeproj`, select an iPhone simulator, and run the `Rationale` scheme.

## Current scope

- Portfolio Overview
- Allocation targets and tolerance
- Monthly contribution Plan calculator
- Optional stock-level targets
- Local persistence with SwiftData

The web and iOS apps are intentionally separate repositories. A shared sync layer can be introduced later without coupling either client to the other client’s local storage.
